# 荒野同行 · 本轮重做系统

用户拒绝上一版几何森林／网站侧栏，明确要求《饥荒》一样的效果。旧设计不再具有视觉权威。新画面是否达标，等待用户对真实运行截图与体验确认，不用自动测试代替视觉批准。

## 首屏与全局构图

Canvas 世界占满整个浏览器视口。左缘为窄制作图标，右上是分段日夜盘与生命／饥饿／理智标记，底部为绘制物品图标的背包。房间、指南、音效不再占一条网页导航栏，而是叠在左上角。地图与聊天保留功能。手机仍提供独立方向和动作键，底部制作切换，背包始终可见。

## 美术与色彩

生成手绘透明精灵，不再用 Canvas 多边形近似树木／角色：两种常青树、灌木、干草、岩石、树枝、幸存者与爬虫，8 个物品图标。强墨线、交叉排线、不对称轮廓与暗橄榄／赭色构成图像语言。地表来自完整绘制纹理，用相邻镜像纹理与不规则地块缓存避免上一版菱形色块。

对照实际 Steam 公开原作截图：粗黑轮廓、头大身细的角色、不规则树枝、世界沉浸式构图与局部营火光照已落实；不宣称拥有原作全部角色动画帧、内容或官方资源。生成提示与来源见 `public/art/PROVENANCE.md`。

## 动作与反馈

服务器通过玩家 action、资源 hitAt、怪物 hitAt 和 hurtAt 同步采集／制作／使用／攻击／受击时间。客户端平滑玩家坐标，四肢独立摆动；采集弯身、攻击挥动、受击偏移／变色，资源短暂摇晃、命中粒子、树草微风、火焰抖动与余烬构成行为反馈。每位持火把玩家均贡献世界光源；夜间营火动态径向光照。前景树遮住自己时变淡。

## 交互与可访问性

对象命中读取实际 PNG alpha，而非整块透明矩形，防止点草却点到后方树。对话框、键盘、触屏与聊天纯文本安全规则保留。素材失败显示错误而不是空白；data-assets 状态用于验收。减少动态偏好关闭装饰微风／粒子与 UI 过渡；关键游戏状态仍实时显示。所有状态有数字与标签，不单靠颜色。

## 验证记录

`tests/game.spec.js`：双浏览器真实动作与共享世界，增加 walk／gather 与同行者动作校验、真实录屏；桌面／手机／夜间截图。
`tests/visual.spec.js`：全屏尺寸、窄制作 HUD、绘制物品、协议快照驱动的攻击／受击渲染与 90 帧性能采样。快照驱动样例仅用于特定动画覆盖，不代替真实多人测试。
本机 Chrome 1280×800 第一轮性能：中位 16.6ms，95 分位 17.2ms，无页面错误。只代表本机，不承诺所有设备帧率。
直接打开检查 alpha-preview、items-preview、desktop、mobile、night 和 attack-hit。机械检测只剩不解析外部 CSS 的 flat-type-hierarchy 提示，实际显示字体有层级。
