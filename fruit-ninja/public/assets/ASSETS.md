# Local game assets

All visual game assets are bundled locally and authored for this project.

- `dojo.svg`: 1280x720 gameplay backdrop.
- `apple.svg`, `orange.svg`, `watermelon.svg`, `kiwi.svg`, `peach.svg`: sliceable fruit sprites.
- `bomb.svg`: hazard sprite.
- `golden.svg`, `ice.svg`, `frenzy.svg`: special item sprites.

Sound effects are generated at runtime through the Web Audio API so playback is instant, offline-capable, and does not require remote media.
