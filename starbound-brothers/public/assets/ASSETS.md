# Asset provenance

The game ships without third-party image or audio files. Characters, terrain, scenery, particles, and UI textures are drawn at runtime from original geometric primitives in `src/game.ts`. Sound effects are synthesized locally with the Web Audio API in `src/audio.ts`.

The game is an original homage to classic side-scrolling platform games. It does not include Nintendo sprites, music, logos, level layouts, fonts, or other proprietary game assets.
