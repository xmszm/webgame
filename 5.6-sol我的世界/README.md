# 5.6-sol我的世界

一个基于 Three.js 的第一人称方块沙盒游戏。世界由种子确定性生成，支持桌面和触控设备，并将玩家的采掘与建造修改自动保存在浏览器本地。

## 运行

```bash
npm install
npm run dev
```

生产构建与本地预览：

```bash
npm run build
npm run preview
```

## 操作

桌面端：`W/A/S/D` 移动，`Shift` 加速，`Space` 跳跃，鼠标控制视角，左键采掘，右键放置，滚轮或数字键 `1-6` 选择方块，`Esc` 暂停。

触控端：左侧摇杆移动，拖动画面控制视角；右侧按钮用于跳跃、采掘和放置，底部快捷栏选择方块。

## 游戏系统

- 36 × 36 × 24 的种子地形，包含草地、沙岸、岩层、海面、树木、云和昼间光照。
- 第一人称重力、跳跃、跑动、方块碰撞、坠落复位和六格建造快捷栏。
- 射线选块、基岩保护、玩家占位保护、采掘粒子、动作音效和即时状态反馈。
- `localStorage` 自动存档、保存退出和带确认步骤的新世界重建。
- 指针锁桌面操作、移动端安全区布局、键盘焦点和原生模态对话框。

## 验证

```bash
npm run check
```

该命令依次执行 ESLint、Vitest 世界逻辑测试、TypeScript/生产构建和 Playwright 桌面与移动端测试。浏览器测试覆盖进入世界、移动、跳跃、采掘、放置、快捷状态、暂停、重建确认、保存恢复、控件溢出、布局相交、控制台错误与画布像素分布，并在 `artifacts/` 生成桌面和移动端截图。
